# WorkFlow

Demo de uma aplicação de orçamentação e acompanhamento de trabalhos para pequenas e médias empresas: serralharias, carpintarias, construção civil e oficinas.

## Funcionalidades demonstradas

- Painel com indicadores comerciais e operacionais
- Lista e estados de orçamentos
- Acompanhamento de trabalhos em quadro visual
- Prazos, responsáveis, progresso e custos
- Dados fictícios prontos para demonstração

## Tecnologia

- ASP.NET Core 8
- Razor Pages
- CSS responsivo sem dependências externas
- Armazenamento em memória para a versão de demonstração

## Executar

Requer o .NET 8 SDK.

```bash
dotnet run
```

Abra o endereço indicado no terminal.

## Próximos módulos

- Criação e edição de orçamentos
- Linhas de materiais e mão de obra
- Geração de propostas em PDF
- Conversão de orçamento aprovado em trabalho
- Anexos e fotografias
- Registo de horas e custos reais
- Autenticação e base de dados SQL Server

Este projeto utiliza dados totalmente fictícios e destina-se a demonstração comercial.
